# فكّر وكمّل – Fakker Wakammel

تطبيق رقابة أبوية تعليمي: يوقف المشاهدة أو اللعب كل فترة يحددها ولي الأمر، ويعرض للطفل سؤالاً، فإذا أجاب إجابة صحيحة أكمل ما كان يشاهده. تتطور الأسئلة مع الطفل حسب عدد محاولاته، وتظهر لولي الأمر تحليلات كاملة.

## محتويات المجلد

| `docs/01_requirements.md` | وثيقة المتطلبات (PRD) |

## التشغيل
```bash
cd app
flutter pub get
flutter test              # اختبارات المحرك
flutter run -d chrome     # نسخة العرض على المتصفح
flutter run               # على جهاز أندرويد متصل
```
يُنشأ الرمز السري لولي الأمر في خطوة الإعداد الأولى. وضع "العرض السريع" مفعّل افتراضياً، فتُحسب المدة بالثواني بدل الدقائق لتسهيل التجربة، ويمكن إيقافه من الإعدادات.
