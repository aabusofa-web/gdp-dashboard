# فكّر وكمّل – Fakker Wakammel

تطبيق رقابة أبوية تعليمي: يوقف المشاهدة أو اللعب كل فترة يحددها ولي الأمر، ويعرض للطفل سؤالاً، فإذا أجاب إجابة صحيحة أكمل ما كان يشاهده. تتطور الأسئلة مع الطفل حسب عدد محاولاته، وتظهر لولي الأمر تحليلات كاملة.

## حالة المرحلة 2 (الإصدار 1.1)
- ✅ ملفات الأطفال (حتى 5 أطفال، مع تحديد الجنس والعمر واللغة)
- ✅ الإيقاف الدوري (محاكاة على الويب) وشاشة السؤال التي لا يمكن تجاوزها، مع عدّ المحاولات
- ✅ المحرك التكيّفي، والتكرار المتباعد، وتصنيف الأسئلة إلى مشترك وذكور وإناث
- ✅ تحليلات ولي الأمر: وقت الشاشة، وتوزيع المحاولات، ومستوى كل مجال، والتطور، ونقاط القوة والضعف
- ✅ إدارة بنك الأسئلة: إضافة وتعديل وحذف ونسخ واستعادة
- ✅ الإعدادات، والرمز السري، والحد اليومي، وواجهة الاشتراك (5 ريال شهرياً، مع 3 أيام تجريبية مجانية)
- ✅ الإيقاف الذكي في أفضل لحظة (ثابت، ذكي، تلقائي حسب العمر)
- ✅ أنشطة التوصيل والرسم، وأسئلة السلوك، والجغرافيا، والتاريخ، والفرنسية
- ✅ مخاطبة الطفل باسمه، وألوان حسب العمر تتغير كل سنة، ومنع التحايل، واختيار الدولة

## المرحلة 3 (أندرويد الحقيقي)
- ✅ خدمة حماية أصلية (Kotlin): تعرف التطبيق المفتوح، وتوقف يوتيوب والألعاب في أفضل لحظة، وتعيد شاشة السؤال عند محاولة الهروب
- ✅ معرفة نهاية الفيديو عبر مشغّل الوسائط، وإيقاف الصوت قبل السؤال
- ✅ حماية الإعدادات والحذف (مدير الجهاز)، والحد اليومي مع تمديد بالرمز
- ✅ وضع التسليم على جوال ولي الأمر: جلسة محددة المدة، وقفل التطبيقات الخاصة، وشاشة "أعد الجهاز"
- ✅ تقارير دورية وتنبيهات فورية للأبوين، مع أوقات هدوء وتحكم بكل نوع
- ✅ ربط جوالي الأب والأم عبر Firebase (الكود جاهز، والتفعيل بعد إنشاء مشروع Firebase: `docs/04_firebase_setup.md`)
- 📄 دليل التثبيت والاختبار: `docs/03_android_install_and_test.md`
- ⏳ المرحلة 4: الدفع الحقيقي عبر Google Play وRevenueCat
- ⏳ المرحلة 5: لوحة الأدمن على الويب

## التشغيل
```bash
cd app
flutter pub get
flutter test              # اختبارات المحرك
flutter run -d chrome     # نسخة العرض على المتصفح
flutter run               # على جهاز أندرويد متصل
```
يُنشأ الرمز السري لولي الأمر في خطوة الإعداد الأولى. وضع "العرض السريع" مفعّل افتراضياً، فتُحسب المدة بالثواني بدل الدقائق لتسهيل التجربة، ويمكن إيقافه من الإعدادات.
